Cette application est un logiciel libre distribué sous licence GNU GPL version 3 ou ultérieure
(fichier LICENSE dans le code source). Elle est gratuite et ne nécessite aucune clé d'API.

Composants embarqués (textes complets dans le dossier « licences » des ressources de l'application) :

- Stockfish 19 (binaire officiel « universal », tag sf_19) — GNU GPL v3.
  Auteurs : voir Stockfish-AUTHORS.txt. Source correspondante :
  https://github.com/official-stockfish/Stockfish/tree/sf_19

  https://github.com/official-stockfish/Stockfish/releases/tag/sf_19 (empreintes SHA-256 dans

Services consultés (facultatifs, sans compte ni clé) : API publique Chess.com, Lichess cloud-eval,
